# Changelog

## 1.0.0 — 2026-08-13

This first native Android release establishes the Aniraku mobile product as an Expo/React Native application with Nothing OS-inspired design primitives, AniList discovery, Aniraku verified-source playback coordination, encrypted Supabase authentication, verified email enforcement, password recovery, synchronized history, bookmarks, episode ratings, comments, notifications, and server-authorized account deletion.
