    GET STARTED

    Install Aniraku.

    One APK. No Play Store. No sign-up. Download, install, watch.

    INSTALL ANDROID 9.0+
    1. 01

      Download the APK — Tap the button above or below to download the latest release.

    2. 02

      Allow unknown sources — Go to Settings → Security → enable "Install unknown apps".

    3. 03

      Install — Open the downloaded APK and follow the prompts.

    4. 04

      Open & watch — Launch Aniraku and start watching immediately.

    On some devices you may need to revoke permission after install to re-enable Play Protect.

    01 Is this app completely free? +

    Yes, Aniraku is fully free and open source with no hidden paywalls, subscriptions, or in-app purchases.

    02 Do I need an account? +

    No. Download the app and start watching immediately. No sign-up required.

    03 Does this track my data? +

    No. Zero analytics, zero telemetry, zero tracking. Your data stays on your device.

    04 What devices are supported? +

    Android 9.0 and above. Both 32-bit (ARMv7a) and 64-bit (ARM64) devices are supported with the universal APK.

    05 Why isn't this on the Play Store? +

    Google prohibits open-source anime streaming apps. We distribute directly via GitHub Releases for full transparency.

    06 Is this legal? +

    Aniraku is an open-source media player that connects to publicly accessible sources. It does not host any content. Consult your local laws regarding streaming from third-party sources.

    07 Can I contribute? +

    Yes. The project is on GitHub — pull requests, issues, and discussions are welcome.
