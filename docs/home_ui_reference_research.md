# Home UI reference notes

The Home-page redesign draws only on high-level public interaction patterns. It does not reuse another service’s images, copy, code, branding, or layout verbatim.

| Reference | Publicly observable pattern | Original Aniraku interpretation |
| --- | --- | --- |
| Animex | A clear featured title at the top, followed by concise discovery groups such as recently added, seasonal favourites, movies, and upcoming releases. It also provides direct category shortcuts near the content. | A single editorial spotlight with a compact live episode ledger, utility-style collection cards, and a contained weekly-programme module rather than repeated Catalog rails. |
| Animex | A mobile-friendly sequence of direct title links with visible episode status and familiar, touch-safe navigation. | Whole-card links, compact metadata, direct watch/detail actions, and a responsive one-column fallback that retains useful episode context. |
| Animetsu.live | The submitted domain redirected to an unrelated third-party commercial page during inspection. It could not be used as a reliable UI reference. | No content, assets, design, or behavior from the redirected destination will be used. |

The design direction is an **editorial anime home page**, distinct from a browsing catalogue: one focused spotlight, a live "on deck" list, purposeful collection tiles, a schedule glance, and personalised continuation content. The visual system remains Aniraku’s dark slate and violet palette.
