# Aniraku Frontend Technology Stack

Aniraku is a Vite-powered React frontend written in JSX. Its source is organized into page components, reusable hooks, and library modules for AniList metadata, Supabase access, synchronization, avatars, slugs, and SEO. Styling is provided by project CSS files, and deployment is described by `vercel.json`.

The frontend should be documented separately from the companion Go backend. This avoids conflating browser code, API services, streaming integrations, and deployment concerns that are maintained in different repositories.
